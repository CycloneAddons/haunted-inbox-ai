# Haunted Inbox AI

<p align="center">
  <img src="Frontend/public/long-logo.png" alt="Haunted Inbox AI" width="450" />
</p>

A simple tool to test and inspect webhooks locally without setting up ngrok or annoying tunnels. You summon a url, send requests to it, see the payload live, and let AI generate typescript types or express handlers for you.

Basically a self-hosted clone of [**webhook.site**](https://webhook.site) with built-in AI. Super useful to test and analyse webhooks from Stripe, GitHub, Shopify, or any payment gateway.

## Features

- Instant webhook urls (no tunnel or dns setup needed)
- Live request stream with websockets
- Useful for analysing Stripe, GitHub, and payment gateway webhooks
- Auto redacts passwords, tokens, card numbers and emails from headers and body
- AI autopsy button to inspect json schema and find weird payload bugs
- Generates ready-to-copy Express.js and TypeScript code

## How to run

### 1. Clone & env
```bash
git clone https://github.com/CycloneAddons/haunted-inbox-ai.git
cd haunted-inbox-ai
cp Backend/.env.example Backend/.env
```

Fill `MONGO_URI`, `JWT_SECRET`, and `ANTIGRAVITY_KEY` in `Backend/.env`.

> I'm using my self hosted reversed eng. antigravity api... u can replace it with OpenAI or any custom api

### 2. Start it up
```bash
cd Backend && npm install && node index.js

cd Frontend && npm install && npm run dev
```

Now open `http://localhost:5173`. You can also just build frontend (`npm run build`) and the backend will serve it on `http://localhost:3000`.

## Quick test

Grab your portal url from the dashboard and throw a request at it:

```bash
curl -X POST http://localhost:3000/h/<your-token> \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer secret_token_123" \
  -d '{"event":"user.created","email":"user@test.com","apikey":"sk_live_12345"}'
```

You will see it pop up instantly on the dashboard with authorization, email, and apikey redacted.
